# data/
* `bangladesh_dengue_weekly.csv` - hackathon-provided weekly ward dataset (60 wards, 2016-01-04 → 2025-12-29). Looks synthetic.
* `ward_coordinates.csv` - **optional, not shipped.** Columns `ward_id,lat,lon`, from a verified source (official ward boundaries/centroids).
  When present, the dashboard's map tab shows a ward-level geographic risk map. Coordinates outside Bangladesh are rejected. We do not invent ward locations.
